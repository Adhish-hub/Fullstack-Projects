
# Project 01 — Student Management System

A full-stack Student Management System built using React, TypeScript, NestJS, MongoDB Atlas, Mongoose, and Tailwind CSS.

The application allows users to create, view, update, and delete student records through a responsive web interface.

## Features

- Create student records
- View all students
- View individual student details
- Update student information
- Delete student records
- Unique email validation
- Backend request validation
- MongoDB persistence
- Responsive interface
- Client-side routing
- Server-state management with TanStack Query
- Error and loading states

## Student Data Model

Each student contains:

| Field | Type | Rules |
|---|---|---|
| _id | ObjectId | Generated by MongoDB |
| name | String | Required |
| email | String | Required, unique |
| age | Number | Integer, 1–120 |
| course | String | Required |
| createdAt | Date | Generated by Mongoose |
| updatedAt | Date | Generated by Mongoose |

## API Endpoints

Base URL: http://localhost:3000

| Method | Endpoint | Description |
|---|---|---|
| POST | /students | Create a student |
| GET | /students | Get all students |
| GET | /students/:id | Get one student |
| PATCH | /students/:id | Update a student |
| DELETE | /students/:id | Delete a student |

### Create Student

POST /students

Request body:

{
  "name": "Rahul Sharma",
  "email": "rahul@example.com",
  "age": 21,
  "course": "Computer Science"
}

### Update Student

PATCH /students/:id

Example request body:

{
  "age": 22,
  "course": "Software Engineering"
}

## Installation

Clone or download the repository and open the project directory.

### 1. Backend setup

Open a terminal:

cd backend

Install dependencies:

npm install

Create a `.env` file based on `.env.example`.

Configure:

PORT=3000
MONGODB_URI=your_mongodb_atlas_connection_string

Start the backend:

npm run start:dev

Backend URL:

http://localhost:3000

### 2. Frontend setup

Open another terminal:

cd frontend

Install dependencies:

npm install

Create a `.env` file based on `.env.example`.

Configure:

VITE_API_URL=http://localhost:3000

Start the frontend:

npm run dev

Frontend URL:

http://localhost:5173

## Architecture

The frontend communicates with the NestJS backend using HTTP requests.

React components handle the user interface.

The service layer handles API communication.

TanStack Query manages server-side data, caching, and mutations.

NestJS controllers receive HTTP requests.

DTOs validate incoming data.

NestJS services implement business logic.

Mongoose communicates with MongoDB Atlas.

## Validation and Error Handling

- Required fields are validated.
- Email addresses are validated.
- Age must be an integer between 1 and 120.
- Duplicate email addresses are rejected.
- Invalid MongoDB IDs are rejected.
- Missing student records return a not-found error.
- Unexpected request properties are rejected.
